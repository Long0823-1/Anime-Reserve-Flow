# Anime Reserve Flow

冬・春・夏・秋に始まるTVアニメを選び、EDCB / EPGTimerのキーワード自動予約へ登録するWindowsアプリです。**v0.1.5**。MAUIによるPixel風の画面を使用します。

## 使い方

1. [Releases](https://github.com/Long0823-1/Anime-Reserve-Flow/releases/latest)のWindows x64 ZIPをすべて展開し、`Anime-Reserve-Flow.exe` を実行します。同じPCで `EpgTimerSrv.exe` を起動してください。
2. 初回だけ「共通設定」でEDCBフォルダー・録画プリセット・必要なら録画後BATを設定し、「保存して接続を確認」を押します。起動中のEDCBを自動検出できる場合もあります。
3. 年・季節を選び、録画したい作品の **「＋追加」** を押します。作品ごとの設定画面を開く必要はありません。
クール全体を選びたいときは **「全○作品を追加」** を押します。絞り込み中でも、取得済みクール全体が対象です。追加済み・登録済み作品は重複させず、編集した設定も保持します。一括追加しただけではEDCBへ送信しません。

4. **「選択した作品を登録」** を押し、確認するとEPGTimerのキーワード自動予約へまとめて登録します。

**ワンセグを除くすべての放送局が対象です。チャンネルの選択操作はありません。** 共通の録画プリセット・BATを使い、検索ワードやBATを変えたい作品だけ「設定を変更」を開きます。作品を追加しても一覧のスクロール位置を維持します。

アニメ一覧にない作品は「一覧になくても手入力で追加」から追加できます。番組表の照合は任意で、0件でも登録可能です。後日、番組表に条件と一致する番組があればEDCBが予約します。登録した条件の変更・削除はEPGTimerで行ってください。

## 共通設定とBAT

EDCBの `EpgTimerSrv.ini` があるフォルダーを指定すると、既存の録画プリセットを読み込みます。録画先・マージン・追従・プラグイン等を引き継ぎます。共通設定の録画プリセットとBATは、今後追加する作品の初期値です。選択済み・登録済み作品の録画設定は勝手に変更しません。

共通BATが未指定なら録画プリセットのBATを引き継ぎます。「プリセットのBATに戻す」はこの共通指定を解除する操作です。特定の作品だけ実行しない場合は、その作品の「設定を変更」で「BATなし」を押します。

TS Encode Flowで作った録画後BATも指定できます。BATと `.bat.profile.json` は作成時の配置に残してください。BATはEDCBが録画終了後に実行します。このアプリがBATを実行したり内容を変更したりすることはありません。

## 予約の動作

検索は番組名のみを対象とする通常のキーワード検索です。空白区切りはAND検索なので、「第2期」「Season 2」などが番組表にない場合は、作品の「設定を変更」で検索ワードを調整してください。除外ワード・現在の番組表での照合も利用できます。

ワンセグはEDCBのサービス情報 `partialReceptionFlag` で除外します。通常の地デジ・BS・CSやサブチャンネルは、ワンセグでなければ引き続き対象です。新規追加・一括追加・番組表照合・未送信作品の送信時に適用し、送信前にはサービス情報を読み直します。ワンセグしか取得できなかった場合は、空のサービス一覧を送らず処理を止めます。

すでにEPGTimerへ登録した自動予約は自動変更しません。既存条件からワンセグを外す場合はEPGTimerで変更してください。録画プリセット・録画後BAT・同時ワンセグ録画などの録画設定は保持します。

ワンセグ以外は全局対象のため、同じ作品の別局放送も条件に一致します。アニメ情報は地域の放送日時・放送局を保証しません。実際の予約は使用者のEDCB番組表と検索条件で決まります。

同じ検索ワードの既存自動予約がある場合は検索条件・録画設定・BAT・放送局を照合します。同じ条件の1件を確認できた場合は、そのIDで登録済みとして表示し、再追加しません。条件が異なる場合や複数候補がある場合は、既存条件のIDとエラーを表示し、上書きせず他の作品の登録を続けます。v0.1.0で保存した未送信作品も、送信時に現在のEDCBの全放送局を対象にします。すでに登録済みの自動予約は変更しません。

## 一覧表示の軽量化（v0.1.3）

季節のアニメ・選択した作品の一覧は、表示範囲とその前後のカードだけを生成します。多数の作品を追加しても、全カードを一度に作らない方式に変更しました。設定保存と録画プリセットの読込みも画面操作を止めない処理へ移し、作品追加時の不要な自動予約一覧の取得を省いています。

自動予約の送信中は、処理中の作品と件数を表示します。作品情報APIの応答やEDCB自体の応答を待つ時間は、一覧の描画とは別に必要です。

## 接続と保存先

Windows 10 バージョン2004以降 / Windows 11 x64向けです。実行用ZIPには.NET / MAUIの実行ファイルを含みます。EXEだけを抜き出さないでください。接続は同じPCの名前付きパイプ `EpgTimerSrvPipe` を使用するため、ネットワークポートの開放は不要です。EDCBと同じユーザーで実行してください。独自のパイプ名・リモートEDCBは未対応です。

設定・選択・一覧は `%LOCALAPPDATA%\Anime-Reserve-Flow` に保存します。作品一覧は6時間キャッシュし、取得失敗時は保存済み一覧と警告を表示します。利用者が指定したクールのみを取得し、全作品DBの収集は行いません。

EDCBのINIや既存自動予約は上書きしません。「一覧から外す」はアプリ内の選択だけを解除します。通信中断時は登録済みの可能性があるため、EPGTimerで確認してください。再操作時にはまず既存条件を照合します。書込みの自動リトライは行いません。

## 登録後も「未送信」のままになる場合（v0.1.4）

旧版では、途中の1作品が重複エラーになると後続の作品が送信されず、最後の案内で原因が隠れる場合がありました。v0.1.4では作品ごとに結果を保存し、失敗した作品を残して後続を処理します。最後に「新規」「既存条件と一致」「失敗」の件数を表示し、「選択した作品」へ移動します。「結果の詳細」で理由を全文確認できます。

旧版を閉じ、修正版のZIP全体を別のフォルダーへ展開して起動し、「選択した作品を登録」をもう一度押してください。選択作品と登録IDは同じ設定フォルダーから引き継ぎます。登録済みIDのある作品は送信しません。登録後の読戻しでは検索条件と録画設定の一致も確認します。

登録先はEPGTimerの **「キーワード自動予約」** です。「予約一覧」へ録画予約が現れるのは、番組表に条件と一致する番組がある場合です。番組表未掲載の次クール作品でもキーワード自動予約自体は登録できます。同名で設定が異なる既存条件を自動変更することはありません。
