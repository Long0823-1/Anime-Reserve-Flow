# Anime Reserve Flow

冬・春・夏・秋のTVアニメを選び、EDCB／EPGTimerのキーワード自動予約へ登録するWindowsアプリです。地デジ・BS・CS・SKY別に録画対象を選べます。MAUIによるPixel風の画面を使用します。

[最新版をダウンロード](https://github.com/Long0823-1/Anime-Reserve-Flow/releases/latest) · [検証記録](docs/VALIDATION.md) · [Ko-fiで開発を支援](https://ko-fi.com/long0823)

## 最初の設定と作品の追加

1. ReleasesのWindows x64 ZIPを全展開し、`Anime-Reserve-Flow.exe`を起動します。同じPCで`EpgTimerSrv.exe`を起動してください。
2. **共通設定**でEDCBフォルダー・録画プリセット・必要なら録画後BATを指定し、**保存して接続を確認**を押します。
3. **共通の対象放送局**で地デジ・BS・CS・SKYを選び、**放送局の選択を保存**を押します。各区分に**全選択／全解除**があり、**局ごとに選ぶ**で個別にも選べます。
4. 年・季節を選び、録画したい作品の**＋追加**を押します。**全○作品を追加**では、絞り込みに関係なく取得済みクール全体を追加できます。
5. **選択した作品を登録**で内容を確認し、EPGTimerの**キーワード自動予約**へ登録します。

追加しただけではEDCBへ送信しません。作品一覧にない作品も手入力で追加でき、番組表の照合が0件でもキーワード自動予約を登録できます。後日番組表に一致する番組があればEDCBが録画予約を作成します。

## 地デジ・BS・CS・SKYの選択

全チャンネルを自動的に対象にする処理は廃止しました。新規設定の初回は**地デジのみ選択**し、BS・CS・SKYは必要な区分の全選択または局ごとのチェックで追加します。以前に保存した共通の局選択がある場合は引き継ぎます。

- 区分の全選択・全解除は、その区分だけに作用します。他の区分の選択は維持します。
- SKYはスカパー！プレミアムサービス等です。BS4KはBS、CS4KはCSに含めます。上記に該当しない局があれば「その他」に表示します。
- ワンセグはEDCBの`partialReceptionFlag`で除外し、選択肢にも表示しません。局名に「ワンセグ」が含まれるかどうかでは判定しません。
- EDCBから取得できない区分は0局です。地デジ以外を選ぶには、EDCB側でも対象局のサービス情報を取得してください。
- 全解除の状態は保存できますが、0局のまま照合・追加・送信はできません。EDCBへ空のサービス一覧を送り、全局検索になることを防ぎます。

共通の選択は**今後追加する作品**の初期値です。追加済みの作品は放送局を保持します。まとめて変更したい場合は、共通設定の**この放送局を未送信作品にも適用**を使います。作品単位では**設定を変更 → 対象放送局**から変更できます。録画プリセット・BATはそのままです。すでに登録した予約は変更せず、EPGTimer側で編集してください。

送信時はEDCBのサービス情報を読み直しますが、保存した選択を全局へ戻しません。取得できた選択局だけを使い、すべて取得できなくなった場合はエラーにします。新しく増えた局を勝手に追加することもありません。旧版で追加済みの未送信作品も、局を自動的に絞り込まず既存の選択を保持するため、必要なら一括適用してください。

## 録画プリセット・録画後BAT

`EpgTimerSrv.ini`のあるフォルダーから既存の録画プリセットを読み込み、録画先・マージン・追従・プラグイン等を引き継ぎます。EDCBのINIは変更しません。

共通BATが空欄なら録画プリセットのBATを引き継ぎます。作品の**設定を変更**では検索ワード・除外ワード・録画プリセット・BATを個別に変更でき、**BATなし**も選べます。TS Encode Flowが作成したBATも利用できます。BATと`.bat.profile.json`は作成時の配置に残してください。BATの実行は録画終了後にEDCBが行います。

## 登録結果と重複

検索は番組名を対象とする通常のキーワード検索です。空白区切りはAND検索なので、「第2期」「Season 2」などが番組表にない場合は検索ワードを調整してください。

同じキーワードの既存予約があれば、検索条件・放送局・録画設定・BATを照合します。同条件の1件を確認できれば登録済みIDを表示し、重複追加しません。条件が違う場合や複数候補がある場合は理由とIDを表示し、上書きせず次の作品を処理します。

結果は作品ごとに保存し、最後に新規・既存一致・失敗の件数を表示します。**結果の詳細**で理由を確認できます。登録先はEPGTimerの**キーワード自動予約**であり、番組表に一致するまで録画予約の一覧に表示されない場合があります。

通信中断時は登録済みの可能性があります。EDCB側を確認し、再操作時は既存条件との照合を行います。書き込みの自動リトライは行いません。**一覧から外す**はアプリ内の作品選択だけを外し、EDCB側の予約は削除しません。

## 保存先・動作環境

Windows 10 バージョン2004以降／Windows 11 x64向けです。実行用ZIPは.NET／MAUIの実行ファイルを含みます。EXEだけを移動しないでください。接続は同じPCの名前付きパイプ`EpgTimerSrvPipe`を使います。ネットワークポートの開放は不要で、EDCBと同じユーザーで実行してください。独自のパイプ名・リモートEDCBは未対応です。

設定・作品・放送局選択は`%LOCALAPPDATA%/Anime-Reserve-Flow`に保存します。作品情報は6時間キャッシュし、取得失敗時は保存済み一覧と警告を表示します。作品カードは表示範囲付近だけを生成し、局ごとのチェック一覧も展開したときに作成します。
