# Anime Reserve Flow

冬・春・夏・秋に始まるTVアニメを選び、EDCB / EPGTimerのキーワード自動予約へ登録するWindowsアプリです。v0.1.0。MAUIによるPixel風の画面を使用します。

## できること

- アニメ一覧や番組表にない作品も、作品名を手入力して自動予約を登録。番組表照合は省略可能。
- 年・季節を選んで日本語の作品一覧を取得（AniList API、TV・短編TV）。検索で絞り込み。
- 作品ごとに検索ワード・除外ワード・録画する放送局を指定。
- EDCBの録画プリセットを読取り、保存先・マージン・追従・プラグイン・録画後BAT等を引継ぎ。
- 録画後BATを共通の初期値として指定、作品ごとに別の `.bat` / `.cmd` に変更、または実行なしに設定。
- 現在の番組表に一致する番組をプレビューしてから、選択した作品をまとめて自動予約へ登録。
- 同じ検索ワードの既存自動予約を確認し、重複登録を停止。選択内容・送信結果を保存。

## 使い方

1. Windows x64用ZIPをすべて展開し、`Anime-Reserve-Flow.exe` を実行します。EXEだけを抜き出さないでください。
2. 同じPCで `EpgTimerSrv.exe` を起動します。「接続・録画設定」で `EpgTimerSrv.ini` のあるEDCBフォルダーを指定し、「保存して接続を確認」を押します。起動中のEDCBからフォルダーを自動検出できる場合もあります。
3. 必要なら共通の録画後BATを選びます。TS Encode Flowの録画後BATも指定できます。BATと `.bat.profile.json` は作成したときの配置に残してください。
4. 「季節のアニメ」で年・季節を選び、一覧を取得します。「録画したい作品に追加」を押します。
5. 日本語タイトルをEPG表記に合わせて編集し、録画プリセット・BAT・放送局を確認。番組表との照合は任意で、0件でも選択一覧へ保存できます。
番組表の照合が0件でも「0件でも条件を保存」で進めます。照合をせずに「番組表に一致がなくても条件を保存」を押すこともできます。一覧にない作品は「一覧になくても手入力で追加」から作品名を入力してください。保存後は「選択した作品」へ移動します。

6. 「選択した作品」の「未送信の作品をEPGTimerへ登録」を押します。確認画面で登録すると、EDCBの **キーワード自動予約** に条件が追加されます。

空白区切りはAND検索です。「第2期」「Season 2」などが実際の番組名にない場合は検索ワードを調整してください。放送開始前は番組表に一致がなくても条件登録できます。作品情報は全国の録画日時・放送局を保証するものではありません。実際の予約は使用者のEDCB番組表と条件で決まります。

録画後BATはアプリが実行するのではなく、EDCBが録画終了後に実行します。既存BATの内容は変更しません。共通BATを変えても、保存済みの選択や登録済み自動予約は変わりません。録画プリセットを選び直すと、そのプリセットのBATを初期表示するので確認してください。

## 接続とデータ

Windows 10 バージョン2004以降 / Windows 11 x64向けです。実行に必要な.NET / MAUIファイルは配布版に含めます。EDCBとの接続は同じPCの名前付きパイプ `EpgTimerSrvPipe` を使用します。ネットワークポートの開放は不要です。EDCBと同じユーザーで実行してください。独自にパイプ名を変更した構成は未対応です。

設定・選択・取得済み一覧は `%LOCALAPPDATA%\Anime-Reserve-Flow` に保存します。作品一覧は6時間キャッシュし、取得に失敗したときは保存済み一覧と警告を表示します。利用者が指定したクールのみを取得し、全作品DBの収集は行いません。

EDCBのINIや既存の自動予約は上書きしません。登録済み条件の変更・削除はEPGTimerで行ってください。一覧から外す操作はアプリ内の選択だけに作用します。登録済み作品の状態は外部で変更しても自動追跡しません。通信中断時は登録が済んでいる可能性があるため、EPGTimerを確認してください。書込みの自動リトライは行いません。
